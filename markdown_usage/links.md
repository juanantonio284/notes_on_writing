# Adding Links In A Markdown Document

The syntax to reference links is: `[normal text][reference name]`. 

In the first box you put text that reads normally (i.e. you can read it in the final document, it's
not hidden code), putting it inside the brackets will make it highlight. In the second box you put
name you want to use to reference the link.

**Example 1**

You can view [this link][youtube], [this link][google], or [this other link][facebook].

[youtube]: https://www.youtube.com/
[google]: https://www.google.com/
[facebook]: https://www.facebook.com/

**Example 2**

<!-- all these lines end with two blank spaces at the end -->
[STEM Education Framework - The New York Academy of Sciences][link_1]  
[Creating Data Literate Students][link_2]  
[How to Help Your Students Develop Data Literacy - Edutopia][link_3]   
[Visualizing Data Series - TED-Ed][link_4]  
[Data Science Lessons - youcubed][link_5]  
[Data Literacy Diigo - The New York Academy of Sciences][link_6]  

[link_1]: https://www.nyas.org/media/13051/gsa_stem_education_framework_dec2016.pdf
[link_2]: http://datalit.sites.uofmhosting.net/books/book/
[link_3]: https://www.edutopia.org/blog/helping-students-develop-digital-literacy-suzie-boss

[link_5]: https://www.youcubed.org/data-science-lessons/
[link_6]: https://www.diigo.com/user/stem_education/?query=%23Data_Literacy

**Example 3**

You can also leave the second box blank and name the reference the same thing as the words that will
be highlighted.
